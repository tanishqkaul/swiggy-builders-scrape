# Start

Pick your path - developer, enterprise, or AI-client consumer.

Three paths in, one platform. Pick the one that matches what you're building.

## Developer - Build an AI agent
Framework recipes for OpenAI Agents SDK, Anthropic, LangGraph, Vercel AI SDK, Mastra, PydanticAI, CrewAI, and Google ADK.

## Enterprise - Power an agent platform
Delegated auth at scale, custom rate limits, and dedicated support for partners running multi-tenant agent platforms.

## Consumer - Use Swiggy in your AI client
Claude Desktop, ChatGPT, Cursor, VS Code, Windsurf. Paste a config, complete OAuth, order food.

## Not sure which?

- If you're **writing code** that calls an LLM and want Swiggy as a tool in that agent → **Developer**.
- If you **operate an agent platform** that your users interact with (voice assistant, in-app agent, chat UI) and need to broker Swiggy on their behalf → **Enterprise**.
- If you're a **user of an existing AI client** (Claude, ChatGPT) and just want Swiggy available inside it → **Consumer**.
- Still unsure - read What is Swiggy MCP? for the primer.
