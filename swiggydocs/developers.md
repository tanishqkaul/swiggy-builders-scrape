## What Could You Build?

Starting points, not limits. These are the kinds of agents and tools that work well on Swiggy's MCP.

Voice Agent - Conversational AI that handles end-to-end food ordering via natural language
Auto-Restock - Instamart agent that learns household consumption patterns and reorders before you run out
Group Ordering - Slack/Teams bot that collects lunch preferences from a team and places a single optimized order
Dietary Planner - Meal planning copilot that filters menus by macros, allergies, and calorie targets
Reservation Agent - Dineout integration that matches group availability, cuisine preferences, and budget constraints
Multi-Modal Agent - Screenshot-to-order pipeline: snap a dish photo, identify it, find it on Swiggy, add to cart

## Your Toolkit

Three MCP servers packed with tools. Pick one or use all three.

### Swiggy Food 
14 tools - Search restaurants, browse menus, manage carts, and place food delivery orders. Build AI agents that handle the entire ordering flow.

### Swiggy Instamart 
13 tools - Search grocery products, manage cart, checkout, and track instant deliveries. Perfect for building smart shopping agents and auto-reorder bots.

### Swiggy Dineout 
8 tools - Search dine-in restaurants, check availability, and book tables. Build dining recommendation agents and smart reservation tools.
